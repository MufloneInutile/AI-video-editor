# AI Video Editor

- `girato/` – il tuo video originale
- `riferimenti/` – esempi che puoi usare
- `export/` – prove e video finali
- `STILE.md` – regole del tuo montaggio
- `STRUMENTI.md` – strumenti usati (Remotion, HyperFrames, FFmpeg, Whisper, yt-dlp)

I file video non vengono caricati su GitHub (vedi `.gitignore`): tienili sul tuo computer o su un cloud (Google Drive, Dropbox).
